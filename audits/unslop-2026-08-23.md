# unslop audit, 2026-08-23

Subject: proposed `unslop` skill, 31 rules, submitted as chat text. Not present in repo (`grep -ril unslop` → no hits).
Scope chosen: technical documents and skill files only.

## Blockers

1. **No "do not invent" rule.** Rules 5, 21, 27, 30 all demand a named source or a number. A rewriter has no source access, so the cheapest way to satisfy them is fabrication. Worst case is the stated use: input is AI text that already carries invented specifics, and the pass hardens them.
2. **No protected regions.** Rules 13, 17, 19, 26, 31 have no carve-out for fenced code, inline code, identifiers, API field names, YAML keys, CLI output, quoted source, URLs. Rule 19 inside a fence breaks the sample. Rule 31 renames a field.
3. **Rule 13 contradicts repo house style.** It bans em dashes entirely. This repo carries 1477 em dashes in `*.md`; `CLAUDE.md` itself 11. It also bans parentheses, and the submitted text uses parentheses 9 times ("landscape (abstract)", "primitive (as noun)", "harness (as metaphor)", ...). Self-violating, and applied it would rewrite every existing document.
4. **Frontmatter missing `version`.** Versioning Policy (`CLAUDE.md`) requires `version` in every `SKILL.md`; all 8 sampled skills carry one (0.0.1 - 0.9.2). `disable-model-invocation` also undeclared; 7 of 8 sampled set it true.
5. **`description` carries no trigger.** "Must always apply" names no phrase, so model invocation will not fire on "clean up this doc". A rule that must always apply belongs in `CLAUDE.md` or an output style, not a skill.

## Conflicts

6. **"Adding soul" against `lv1-doc-writer` §A1.** unslop: have opinions, use "I", let some mess in, "impressive but also kind of unsettling". A1: no self-explanation, measurable over adjectival, one fact per bullet. Two skills give opposite orders on the same sentence. unslop also contradicts itself: rule 27 says say what it does, not how it feels.
7. **Specificity demand with no escape.** Rule 27 wants a mechanism or a number, rule 30 wants the measured delta. Where the input has neither, the only safe edit is to cut. Not stated.
8. **Domain terms blacklisted.** Rule 26 lists harness, surface, scaffolding, primitive; rule 7 lists landscape, showcase, crucial. This repo uses harness as a real term: "the area's own harness" (`specs-builder` description), "test harnesses" (`CLAUDE.md`, Repository Layout). "API surface" is a term of art. No keep-when-domain-term exemption exists.

## Structure

9. **Duplicates.** Against `CLAUDE.md` "Report each finding once": fostering in #3 and #7; showcasing/showcase in #3 and #7; landscape in #1 and #7. Three word lists do one job (#7 AI vocabulary, #26 abstract metaphor nouns, #31 plain word). #23 filler overlaps #24 hedging.
10. **31 flat rules, no tiers, no stop condition.** Predicted behaviour is a vocabulary substitution pass with #27-#31 skipped, which are the rules that matter for docs.
11. **No output contract.** Does not say whether to return edited text, a patch, or edit in place. No change log, no meaning-preservation check. Step 4 ("What makes this obviously AI generated?") is unverifiable and unbounded.
12. **No length handling.** A long document in one pass degrades to the first few paragraphs.
13. **Two examples for 31 rules** (#14, #27). Before/after pairs outperform word lists on edit tasks.

## Out of scope for docs

14. #2 name-dropping media outlets, #4 promotional travel adjectives (nestled, breathtaking, must-visit), #6 formulaic challenges, #22 sycophancy. Journalism and chat provenance. Dead weight in a docs pass, and they dilute attention from #27-#31.

## Missing tells

- Transition adverbs: Moreover, Furthermore, Firstly/Secondly, Importantly, "That said" with nothing said.
- Corporate adjectives: seamless, robust, comprehensive, streamline, empower, unlock, elevate, game-changer, best-in-class, at scale.
- Openers and closers: sentence 1 restating the request, "Let's dive in", "In today's fast-paced world", rhetorical-question opener, "you might be wondering", closing paragraph repeating the opener, "Key takeaways", "TL;DR".
- Minimizers: simply, just, "all you need to do".
- Structural symmetry: equal-length sections, every list 3-5 items, Overview/Benefits/Challenges/Conclusion shape. #10 catches only in-sentence triads.
- Fake precision: invented numbers, dates, version strings.
- Second-person coaching tone in reference documents.
